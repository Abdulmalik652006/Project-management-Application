WORK FORGE – Project Management System

WORK FORGE is a full-stack Project Management Web Application designed to help teams plan, manage, and track projects efficiently. It provides a modern UI, role-based workflows, and a scalable backend architecture.

WORK FORGE is a full-stack Project Management Web Application designed to help teams efficiently plan, manage, and track their projects. It features a modern user interface, role-based workflows, and a scalable backend architecture suitable for growing teams.

🚀 Features

👤 User Authentication & Role Management

📋 Project Creation & Management

✅ Task Assignment and Status Tracking

📊 Project Progress Overview

🎨 Responsive UI using Tailwind CSS

⚡ Fast Frontend Development with Vite

🧩 Modular and Scalable Backend Structure

Frontend

Vite

Backend

Node.js

PostCSS

Tailwind Configuration

⚙️ Installation & Setup
Prerequisites

Node.js v16 or higher

npm

Steps

Clone the repository

git clone https://github.com/Jeevan4125/Project-Management-WORK-FORGE-.git

Navigate to the project directory

cd Project-Management-WORK-FORGE-

Install dependencies

npm install

Run the frontend

npm run dev

Run the backend (if applicable)

cd backend
npm install
npm start
